# Dataset

본 프로젝트는 **Roboflow Universe의 DMD (Driver Monitoring Dataset, v6, CC BY 4.0)**
를 사용한다. 라이센스 정책 및 용량 문제로 원본 데이터셋을 본 repo에 직접 포함하지 않는다. 

## Download

1. (https://www.kaggle.com/datasets/zeyad1mashhour/driver-inattention-detection-dataset/code) 접속
2. 다운로드한 ZIP을 압축 해제하여 그 다음 수행 **위에 나와있는 것처럼 Roboflow Universe에 접속하여 다운로드해도 무관**
